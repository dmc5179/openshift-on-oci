For the autoscaler,
We pre-stage the three provider manifests and the Helm chart/index on an internal webserver.
We also mirror the required images and rewrite the manifests/chart to use private registry digest references.

```
**Module inputs and manifest URL construction:**

```
variable "provider_artifacts_base_url" {
  type    = string
  default = ""
}

variable "cluster_autoscaler_repository_url" {
  type    = string
  default = "https://kubernetes.github.io/autoscaler"
}

variable "provider_installer_image" {
  type    = string
  default = "quay.io/openshift/origin-cli:4.20"
}

locals {
  # Uses the existing cert_manager_version, capi_version and capoci_version.
  provider_artifacts_base_url = trimsuffix(
    trimspace(var.provider_artifacts_base_url), "/"
  )

  cert_manager_manifest_url = local.provider_artifacts_base_url != "" ? (
    "${local.provider_artifacts_base_url}/cert-manager-${local.cert_manager_version}.yaml"
  ) : "https://github.com/cert-manager/cert-manager/releases/download/${local.cert_manager_version}/cert-manager.yaml"

  capi_manifest_url = local.provider_artifacts_base_url != "" ? (
    "${local.provider_artifacts_base_url}/cluster-api-${var.capi_version}.yaml"
  ) : "https://github.com/kubernetes-sigs/cluster-api/releases/download/${var.capi_version}/core-components.yaml"

  capoci_manifest_url = local.provider_artifacts_base_url != "" ? (
    "${local.provider_artifacts_base_url}/cluster-api-provider-oci-${var.capoci_version}.yaml"
  ) : "https://github.com/oracle/cluster-api-provider-oci/releases/download/${var.capoci_version}/infrastructure-components.yaml"
}
```

**Add these entries to the existing ConfigMap's `data` inside the Terraform heredoc:**

```
  CERT_MANAGER_MANIFEST_URL: "${local.cert_manager_manifest_url}"
  CAPI_MANIFEST_URL: "${local.capi_manifest_url}"
  CAPOCI_MANIFEST_URL: "${local.capoci_manifest_url}"
```

**The provider-installer Job uses the configurable image and ConfigMap:**

```
      containers:
      - name: provider-installer
        image: ${var.provider_installer_image}
        envFrom:
        - configMapRef:
            name: oci-capi-operator-config
```

**Replace the three hardcoded downloads in its Terraform heredoc with these commands, keeping the existing transformation, apply and wait steps:**

```
oc apply -f "$${CERT_MANAGER_MANIFEST_URL}"

curl -LfsS "$${CAPI_MANIFEST_URL}" \
  -o /tmp/capi-core-components.yaml

curl -LfsS "$${CAPOCI_MANIFEST_URL}" \
  -o /tmp/capoci-infrastructure-components.yaml
```

The double dollar signs escape shell variable interpolation in Terraform.

**In the generated `OCIClusterAutoscaler` CR:**

```
spec:
  clusterAutoscaler:
    repositoryURL: ${var.cluster_autoscaler_repository_url}
```

For example, the module receives:

```
provider_artifacts_base_url        = "http://abi.example.internal/autoscaler"
cluster_autoscaler_repository_url  = "http://abi.example.internal/autoscaler/charts"
provider_installer_image           = "registry.example.internal/openshift/origin-cli:4.20"
```

The internal webserver serves:

```
/autoscaler/cert-manager-v1.16.3.yaml
/autoscaler/cluster-api-v1.14.0.yaml
/autoscaler/cluster-api-provider-oci-v0.24.0.yaml
/autoscaler/charts/index.yaml
/autoscaler/charts/cluster-autoscaler-9.40.0.tgz
```

The Helm index uses internal or relative chart URLs, and the chart renders a private registry image. For air-gapped installations, we transfer both the mirrored images and these artifact files into the isolated environment before installing the autoscaler.
```

This needs to be wired through both create-cluster and create-autoscaler-operator, including the root Terraform inputs and Resource Manager schemas.
